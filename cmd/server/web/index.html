Double-entry ledger engine · Go

Money that can't go missing.

A single-writer state machine posts every transfer as a balanced debit and credit, guarded by idempotency keys and a write-ahead log. Concurrent payments and retried requests, the two things that quietly corrupt naive ledgers, can't break the books.
